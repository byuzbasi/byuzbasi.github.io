# Prof. Dr. Bahadır Yüzbaşı

Kişisel akademik web sitesi: [byuzbasi.github.io](https://byuzbasi.github.io)

İnönü Üniversitesi Ekonometri Bölümünde İstatistik Profesörü. Araştırma alanları; istatistiksel öğrenme, yüksek boyutlu veri, penalize regresyon, fonksiyonel veri analizi ve mekânsal istatistiktir.

Sitede yayınlar, atıflar, araştırma projeleri, ders materyalleri, R/C++ yazılımları, akademik etkinlikler ve özgeçmiş yer alır.

## Teknik notlar

- Site, [al-folio](https://github.com/alshedivat/al-folio) ve GitHub Pages ile yayımlanır.
- Yayın kayıtlarının ana kaynağı [`publications.bib`](publications.bib) dosyasıdır.
- Ana sayfadaki seçilmiş yayınlar, ilgili BibTeX kaydında `selected = {true}` alanı ile yönetilir.
- Ziyaret istatistikleri GoatCounter üzerinden izlenir.
